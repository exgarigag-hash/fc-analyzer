# FC 전력분석실

## 파일 구성
- app.py : 웹 앱 (Streamlit)
- common.py : 앱과 수집기가 같이 쓰는 코드 (API, xG 모델, DB 저장)
- collector.py : 자동 수집기
- schema.sql : 데이터베이스 설계 (Supabase에서 한 번 실행)
- .github/workflows/collect.yml : 3시간마다 수집기를 돌리는 설정

## 분석 방식
- 진단: xG(기대 득점)로 득실을 찬스 창출 / 결정력 / 수비 조직 / 막판 방어로 분해
- 판정: 부트스트랩 2000회. 95% 확신이면 "확실", 80%면 "가능성", 그 밖은 "판단 보류(몇 경기 더 필요)"
- 비교 기준: 같은 등급 유저 30명 이상(유저당 10경기 이상)이 쌓이면 등급 분포와 비교하고 상위 %를 표시.
  그 전에는 찬스 창출과 수비 조직을 합친 "찬스 싸움"으로 판단
- 패치: patches 표에 패치 날짜를 넣으면 현재 패치 데이터 우선으로 비교
- 스카우팅 카드, 매칭 전략, 질 때 공통점은 그대로 유지

## 넥슨 약관 대응
- 수집 데이터는 30일 이내 갱신 의무가 있어서, 유저 정보는 25일마다 갱신하고 경기 기록은 28일 뒤 삭제
- 삭제 전에 유저 정보 없는 익명 집계(patch_tier_agg)만 남겨서 패치별 추세 분석에 사용
- 앱 하단에 "Data based on NEXON Open API" 표기
