# FC 전력분석실 실행 방법

1. API 키 발급: https://openapi.nexon.com 로그인 → 애플리케이션 등록 → 게임 "FC 온라인" 선택 → 키 복사
2. 설치: `pip install -r requirements.txt`
3. 실행: `streamlit run app.py` → 브라우저가 열리면 사이드바에 키 입력
   (매번 입력하기 싫으면 환경변수 NEXON_API_KEY 에 넣어두면 자동으로 들어감)

## 분석 방식
- 상대 스카우팅: 최근 10경기로 3초 스카우팅 카드(공략·주의·전략·경고). 내 닉네임을 같이 넣으면 내 강점 × 상대 약점 매칭 전략까지
- 질 때 공통점: 이긴 경기 vs 진 경기 비교 (각 3경기 이상 필요)
- 최근 N경기(몰수 경기 제외)에서 "나"와 "같은 경기에서 만난 상대"의 지표를 경기별로 비교
- 효과크기 = 경기별 차이의 평균 / 표준편차. +0.3 이상이면 강점, -0.3 이하면 약점
- 시간대별 득실, 슈팅 맵, 선수별 기록, 플레이 스타일 태그 제공

## 참고
- 개발용 키는 호출 한도가 있어서 경기 수를 많이 잡으면 느릴 수 있음 (한 번 불러온 경기는 캐시됨)
- 슈팅 맵 좌표 방향이나 골 시간 값은 넥슨 API 표기 방식에 따라 조금 어긋날 수 있음
